## โปรเจ็คนี้คืออะไร

**Student Skill Matcher** — เว็บแอปพลิเคชัน PHP สำหรับวิทยาลัยอาชีวศึกษา
ใช้บันทึกความถนัด/ทักษะของนักเรียนแต่ละคน แล้ว Match กับสายการแข่งขันที่เหมาะสม

**วิชา:** 31903-2008 การพัฒนาเว็บแอปพลิเคชันด้วย PHP (ภาคเรียน 2/2569)
**ทีม:** 2 คน ทำงานบน repo เดียวกัน

---

## ทีม

- **Developer A:** นายณัฐกานต์ บัวทุม — ฝั่งข้อมูลนักเรียน + ระบบ Match
- **Developer B:** (เพื่อนร่วมทีม) — ฝั่งสายแข่ง + ระบบ Admin ครู

---

## Tech Stack

- **Backend:** PHP 8 (plain PHP ก่อน → Laravel สัปดาห์ 13)
- **Database:** MySQL/MariaDB ผ่าน PDO
- **Frontend:** HTML, CSS, JavaScript (ไม่มี framework JS)
- **Server:** XAMPP (localhost พัฒนา → Host จริงสัปดาห์ 14)
- **VCS:** Git + GitHub

---

## โครงสร้างระบบ (Domain)

```
นักเรียน (Student)
  └── มีทักษะ (Skill) หลายอย่าง เช่น Web Front-end, Database, Network
        └── แต่ละทักษะมีคะแนน/ระดับ

สายแข่งขัน (Competition)
  └── ต้องการทักษะ (Requirement) หลายอย่าง
        └── ระบุว่าต้องการทักษะอะไร ระดับขั้นต่ำเท่าไร

Match
  └── เปรียบเทียบ Skill ของนักเรียน กับ Requirement ของสาย
        └── แสดงผลว่าเหมาะกับสายไหนมากที่สุด
```

---

## Database Tables (เป้าหมาย)

| ตาราง | คำอธิบาย |
|-------|---------|
| `users` | บัญชีผู้ใช้ทั้งหมด (role: student / teacher) |
| `students` | ข้อมูลนักเรียน (เชื่อมกับ users) |
| `skills` | ทักษะที่นักเรียนมี + คะแนน |
| `competitions` | รายการสายแข่งขัน |
| `requirements` | ทักษะที่แต่ละสายแข่งต้องการ |
